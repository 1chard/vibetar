# Fortnite Festival keyboard

USB mode 3 is an NKRO keyboard (all guitar inputs may be held together).
MODE cycles HID gamepad → Guitar Hero → Rock Band → Keyboard → HID gamepad.
The optional short Start + Select chord uses the same cycle. XInput-only policy
continues restricting the cycle; hold Start + Select for 3 seconds to recover HID.

The defaults target Festival Pro Lead / Pro Bass: green–orange use 1–5;
strum up/down use Right Shift / Enter; Tilt uses Page Down; whammy uses Right
Ctrl. Start is Escape, Select is Backspace, Guide is disabled and left/right use
arrow keys. Solo frets use the corresponding normal fret mapping. The effects
selector does not generate keys.

Connect the guitar or receiver to the editor and use **Teclado · Fortnite
Festival Pro**. Each input can be rebound to a USB HID keyboard usage or disabled.
Save with **Salvar teclado no Pico**. Preset resets the draft; save to persist.
The keyboard section participates in JSON import/export and unsaved-change checks.

Whammy uses its existing normalized/calibrated 0–65535 value. The default activation
threshold is 8192 (12.5%) and hysteresis is 2048. The key releases below 6144.
Enable/calibrate the analog whammy input separately. This is a digital keyboard
key; it does not transmit an analog axis.

On the receiver, the receiver's saved keyboard mapping converts received guitar
state into USB keys. BLE between guitar and receiver keeps the original control
packet; native BLE gamepad reports remain gamepad reports. Direct Bluetooth
keyboard output is not part of this mode. Update both UF2 files for the expanded
mode feedback. The USB keyboard has its own serial suffix K to separate cached
descriptors and retains vendor configuration reports for the editor.

Feature 35 reads/writes the keyboard profile; Feature 36 reads defaults. Both
have 24-byte payloads, over USB configuration HID and guitar BLE configuration:

| Bytes | Meaning |
| --- | --- |
| 0 | Version 1 |
| 1 | Shared save status; SET requires zero |
| 2–15 | Keyboard usages: 11 main buttons, left, right, whammy |
| 16–17 | Whammy threshold, uint16 LE |
| 18–19 | Hysteresis, uint16 LE |
| 20–23 | Reserved zero |

Usage zero disables a binding; valid keys are 4–231, including modifiers.
Duplicate mappings are merged so releasing one source does not release another
held source. No input macros or automatic repeats are generated by the firmware.
Flash XFC8 appends this profile at offset 120 and moves CRC to 144. XFC1–XFC7
remain readable and receive keyboard defaults. Factory reset restores the preset.

In-game bindings can differ from the published defaults; match the keyboard
profile to Festival's Pro Lead / Pro Bass bindings. Hardware/game validation is
still required, especially for keyboard compatibility on consoles.
